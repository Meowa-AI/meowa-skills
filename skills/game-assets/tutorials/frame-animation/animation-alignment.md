# 帧动画处理：跨动作锚点验收与位置矫正

同一角色的不同动作即使各自播放正常，切换时仍可能瞬移：动作需要的四向 padding 不同，导致角色在各文件画布中的位置不同。**一套动作生成、裁帧和去背景后，必须在同一游戏位置连续切换验收；有画布偏移时，交付前尽量用额外 padding 统一角色锚点。** 已确认对齐且切换无误时，记录通过即可，不重复矫正。

本流程适用于 Pixel 和 HD。先按[动画制作](animation-production.md#6-动画校验先整体动作与画布再看细节)确认动作与裁切可用，再处理位置；不靠对齐补救错误动作或缺失画面。

## 1. 先 review，确定要固定什么

- 选已验收的待机或站立姿势作基准，确定身体根锚点与地面线。横版角色通常以站立时双脚之间的地面位置作参考；俯视角色按游戏使用的身体根部／接地点确定。优先让身体根锚点水平居中，并统一站立地面高度，不要求人物在纵向几何居中。
- 锚点不等于整张图的中心、所有可见像素的重心或外接框中心。尾巴、头发、武器、伸出的拳头和特效都可能改变这些统计量；跳跃时也不能把当前最低像素当作地面。
- 区分 **padding 导致的整段偏移** 与 **动作本身的位移**。跳跃、奔跑前倾、受击后仰、倒地及设计允许的击退需要保留。统一的是游戏放置基准，不是要求每帧的脸、重心或脚底坐标完全不动。
- 在固定画面位置，以相同原像素尺度依次播放待机→行走／奔跑→待机、待机→受击／攻击→待机，以及倒地→起身等实际切换。叠加基准姿势、中心线和地面线，先判断是否有误差；画布大小相同不代表角色已对齐。

## 2. 按证据选择锚点估计方法

| 证据 | 处理方式 | 复核重点 |
|---|---|---|
| 已记录母版锚点、四向 padding 和后续裁切偏移 | 优先换算各动作锚点；先核对生成结果是否沿用了该坐标 | 后处理、生成漂移或裁切是否使记录失效；不能只看输入已对齐 |
| 首帧是相同或近似相同的姿势 | 用透明主体掩码与颜色／轮廓做整数平移匹配，输出候选偏移和相似度 | 同时检查轮廓重叠、外观差异和叠图；不能只凭一个分数自动认定成功 |
| 首帧不同，但有共同准备姿势、收势帧或原始输入 | 匹配可比姿势，并结合来源记录继承锚点；可检查多个相近帧降低偶然误差 | 奔跑循环裁掉起步帧后，不能假设导出首帧仍是原始首帧；不抹掉真实运动 |
| 同一原片拆出的倒地／起身或连续动作 | 继承同一原片的锚点和同一平移，核对共享端点 | 不分别按倒地和站立的重心居中，否则会破坏原本一致的衔接 |
| 无可比姿势、无可靠来源记录 | 脚本用主体连通区域、身体位置、重心或接地点给出粗略候选，再由 Agent 看叠图和连续播放微调 | 伸腿、离地、趴卧、非对称装备与特效容易误导；低置信度时保留待审，不强行自动修正 |

匹配前应已有干净透明图，排除杂点、背景和无关特效对定位的影响；定位用的掩码处理不应改变导出素材。只做平移匹配不能解决角色比例变化、缩放或严重变形；遇到这些问题先说明并单独处理。相似度阈值须按当前素材验证，不把某个角色的试验阈值当作通用保证。

## 3. 每段只应用一个固定偏移，用 padding 统一画布

**同一动画的所有帧应用同一个整数平移；不逐帧按重心或外接框重新居中。** 后者会消除跳跃、引入脚滑和抖动。动画本身的非预期漂移应另行判断，不混进跨动作 padding 矫正。

设各文件原画布为 `Wi × Hi`，已复核锚点为 `(ai, bi)`，坐标以画布左上角为原点，边界按像素边界计。仅增加 padding、保留完整原画布时，可以这样选统一画布：

1. 水平半宽 `C = ceil(max_i(ai, Wi - ai))`，新宽 `2C`，共同锚点横坐标 `C`。
2. 地面高度 `G = ceil(max_i(bi))`，新高 `G + ceil(max_i(Hi - bi))`；可按项目需要再加共同安全边距。
3. 每段的粘贴偏移为 `(C - ai, G - bi)`，确保为非负整数且原画布完整放入。整套使用同一输出画布和同一锚点。

这些尺寸从实际素材算出，不是生成阶段的固定画幅。生成时仍按动作留空间；统一交付画布放在生成之后完成。Pixel 不缩放、不平滑、不改颜色或 alpha；HD 同样优先直接粘贴保留原像素与软透明。背景保留版使用相同偏移和相应背景色；独立音频在只加 padding 时无需改时序。

若项目支持逐动作 pivot／offset，也可保留不同画布并交付统一锚点元数据，但必须按真实引擎放置规则验收。用户希望文件直接切换播放时，优先统一画布加 padding。已正确对齐的整套无需改文件；有可靠锚点元数据时重复运行应保持原结果，不反复加边。

## 4. 交付验收

- **切换：** 对齐前后使用同一时间轴、原像素尺度和固定游戏位置比较；检查准备姿势的身体位置、地面线、动作结束与下一动作的接点。没有 padding 引起的跳位；保留设计允许的运动。站姿不同导致的轮廓变化不能都解释成位置误差。
- **完整：** 全帧检查手脚、武器和特效未因平移被裁掉；倒地→起身等共享端点仍对齐。补 padding 不能恢复源文件中已有的裁切。
- **无损：** 重新打开导出文件，核对可见像素和 alpha、帧数、每帧时长、播放顺序与循环属性；仅加边不应改变这些内容。保留原件，另存矫正版。
- **可复核：** 记录基准动作、锚点定义、来源尺寸、候选与最终偏移、匹配证据／人工调整、输出画布及通过或待审结论。匹配可靠与动作整体可用是两项不同结论；没有 review 的候选不标成成品。

辅助脚本宜分“分析候选→Agent review→按已确认偏移导出”三步。分析先生成报告、叠图与连续切换预览；不确定时允许手动指定锚点或跳过，不能静默套用重心估计。经验表明，同姿势匹配适合处理 padding 差异，原片来源可帮助处理裁帧／拆段，而重心只能作为不同姿态的初始参考。
