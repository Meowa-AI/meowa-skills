# 角色设计：像素与高清共用

本教程用于从概念或参考图确定角色、怪物与 BOSS 的外观，供静态素材、高清动画和像素动画复用。先确定设计，再选择符合目标尺寸和画法的生成路线；已有定稿时直接进入参考与验收，不必重新发散。

## 1. 从设定推导可见外观

从零设计角色或怪物时，可先结合**故事背景、能力与核心元素**形成相对完整的概念，再反推外观。故事背景提供身份与来源，例如仙侠、克苏鲁或两者融合；能力可以是喷火、施毒、操纵黑暗或召唤；核心元素则提供造型基础，例如丹炉与八爪鱼。说明这些设定如何关联，再据此确定体型、身体结构、材质和装备，而不是只把元素作为装饰贴上去。例如“被深海邪物寄生、以炉火炼食的丹炉”，可以推导出吞食用的炉口、抓取猎物的触须炉足和透出火光的炉腹。不必每次凑齐所有设定，已有定稿时也无需重新发散。

把概念写成生图提示词时，**以可见的外观描述为主**，不要依赖模型从专有名词或文学概念推导具体画面。背景和名称可以少量保留作语境，但关键元素、形状、材质、位置及关系要直接说清。例如“照骨镜”可展开为“白骨构成的镜框，漆黑的镜面”；若设定为空镜，再明确“镜内没有人物、骷髅或其他影像”。能力若影响外形，也应落到可见结构上，而不是只写一个能力名称。

## 2. 明确参考图用途与设计自由度

- **多参考融合设计：** 说明最终外观、姿态和各参考的用途，例如“脸和服装参考图一，锅和尾巴参考图二”。明确只保留哪些元素，避免把照片背景、容器或多视图版面一起带入。多图不必先合图；上传张数本身不能说明质量或稳定性。
- **已有设计的复刻或编辑：** 把已认可图片作为身份参考，只描述需要改变的部分。小幅调整可写“保持外观，将动作改为……”。大幅动作、复杂遮挡或装备位置变化，用万能编辑准备对应姿态，再验收外观与结构。
- **转换绘制风格：** 将造型要求与目标画法分开描述，不默认允许重新设计。高清转像素的尺寸、简化和描边取舍见[像素流程](pixel.md#2-高清设计转像素或直接像素生成)。

生成式AI更擅长发散探索，未必能100%遵循既定设计；严格复刻通常需要更多尝试和验收。先区分目标：已有定稿且要求一致时，继续围绕参考图控制外观；允许探索时，可以纯提示词驱动，或仅用概念图提供美术风格，不要求逐处复刻，让模型发挥造型想象。怪物、道具等开放设计尤其适合后一种方式。

探索提示词可以比转换提示词详细，例如用约100～200字交代主题、剪影、比例、材质、配色、用途和允许发挥的空间；内容足够即可，不凑字数或堆质量词。这个长度用于开放设计，不套用到单纯像素转换或动画动作描述。先从发散结果中选定设计，再固定参考和工作流制作后续资产；用户要求严格还原时，不擅自放宽为自由创作。

## 3. 选择画法与角色画幅

角色造型、绘制语言与生成路线分别判断。探索画法时，单独定义色彩、轮廓、明暗与纹理。例如水墨看笔势、飞白和虚实，铜版画看刻线与点阵，赛博风看暗面和局部发光；不要把灰度化、铜金换色或霓虹描边直接当作风格完成。彩色定稿参考可能连同原画法一起保留；若变化受限，可比较纯文字或只用风格参考的重绘。参考也可能带入不需要的主体、版面或文字，必须看真实结果。

**按角色体型与轮廓选画幅。** 直立石像、背部高藤架或长角角色可试3:4，特别细长时再考虑9:16；爬虫、横向长尾或展开肢体的角色可用横幅。支持自由尺寸的路径直接设置相应宽高，不强塞方形，也不事后拉伸。固定模板仍遵循其尺寸契约。验收实际主体边界、留白和肢体完整性；关闭填满画布与提示“不裁切”都不能代替检查。

高清角色可用 `general-image-run` 设计、用 `image-edit-run --mode hd` 调整，也可选择匹配的高清模板。根据当前命令 `--help` 选择模型、比例、质量和分辨率；模板的尺寸与数量仍是固定契约。具体参数见[角色生成能力](../../references/pixel-and-hd-assets.md)和[万能编辑](../../references/ui-and-image-editing.md#edit-still-images)。高清定稿可直接进入[动画制作](animation-production.md)，不需要经过像素化。

角色后续要做绿幕动画时，**生成图片后必须先完成去背景与透明边缘验收，再填充绿幕**；直接填绿会保留原背景和轮廓杂边，容易在动画中产生大量边缘残留。生图尽量直接输出透明背景；Image2.5 生图／编辑可开启 `--remove-bg-method standard`，去背景不收附加费，生成与参考图仍按正常计费。下载后检查实际 alpha 和轮廓；已有干净透明图无需重复抠图，否则按[动画输入背景准备](animation-production.md#先准备透明角色图再填充绿幕)补做去背景并验收，再进入动作生成。

## 4. 验收并固定设计

先看完整轮廓、比例、脸与关键装备，再看色彩、材质、绘制语言和细节。按最终使用尺寸确认设定能被看懂，而不只是提示词里写过：例如经书前肢应能辨认封面、书脊与厚书页，不能只剩带齿的板片。检查全身与道具是否完整、是否裁切、主体边界与留白是否合适；关闭填满画布或写“不裁切”都不能代替检查。

把身份保留、装备位置、动作变化、画面完整性和审美偏好分开评价。需要透明时实测 alpha；参考不需要的文字、背景和主体不得混入成品。设计未通过时先调整设计或参考，再扩展整套或制作动画。

比较候选时保留原件与固定编号，记录参考、提示词、模型、模板和参数，可用预览页让用户选择。排查原因时固定其余条件；同一次任务的多个输出不算独立重复，不从一次抽卡推断通用优劣。满意后固定母版与工作流，后续仅局部调整。
