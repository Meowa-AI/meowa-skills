# 动画导出：游戏资源与宣传资源

从已验收的最终素材导出，保留原件，处理结果另存。生成前的背景确认见[动画制作](animation-production.md#生成前确认背景用途)。

## 1. 先确认导出用途

用户要求导出到某个目录、用途不明时，可先询问是游戏资源，还是宣传／社交媒体传播资源；用途已明确时直接执行。再按用途确认格式、尺寸、背景和是否合入音效。

## 2. 游戏资源

按项目要求导出尺寸、透明度、格式、帧序列／图集、循环、锚点与音频，不自动放大或改成白底。需要多个动作切换时，按[跨动作锚点验收](animation-alignment.md)处理。模型时长档位是近似值，只有项目要求精确时间轴时才另行调整。

## 3. 宣传／社交媒体资源

- **背景：** 无需抠图时建议白底。已有透明素材可逐帧合成到白底；已有不透明背景不能仅靠填白透明区域替换。
- **像素放大：** 可按展示需要用邻近采样做整数倍放大，例如宽高各 2 倍。静态图与动图所有帧采用相同倍数，保持每帧时长、顺序和循环设置；放大在导出阶段进行，不为宣传尺寸放大动画生成输入。
- **组合动作：** 游戏里由多段实时组装的动作（三连击、传送的消失与出现、倒地与起身等），单看某一段看不出效果。宣传导出时可按游戏里的顺序合成一个动图：各段按锚点对齐到同一画布，保持各段原有帧时长，需要停留的姿势可加停顿，结尾稍作停留再循环；合成后裁去多余留白。组装方式见[组合动作](../frame-animation-postprocess/combo-assembly.md)。
- **图片格式：** 可交付 PNG 与无损 WebP。需要保证无损时检查实际编码与解码像素，不能仅凭 `.webp` 扩展名判断。
- **带音效视频：** 可将最终动画与对应 WAV 合成 MP4，用于音画一起播放。常用 H.264 视频与 AAC 音频；保留无损图片原件，不把常用 MP4 编码当作无损母版。

合成 MP4 时，使用最终动画的逐帧时间累计视频时间戳，与音效对齐起点，保留末帧停留。源动画经过裁切或变速时，使用同步处理后的音效。不要仅指定固定帧率而丢帧或改变节奏；导出后完整播放，核对尺寸、实际时长、音轨与主要声画事件。

## 4. 目录整理与复核

可按“静态图／动图／视频／音效”分目录，只建立本次需要的目录；用角色或怪物名称对应命名，有多个动作时追加动作名。按用户要求提供设计说明，并同步实际尺寸、背景与时长。

保留原版备份，只收录已选定的最终版本；中间帧、调试文件和失败候选不混入交付目录。重新打开导出文件，确认背景、像素边缘、帧时序、循环与音效符合已确认的用途。
