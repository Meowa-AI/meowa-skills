# 帧动画后处理与二次处理

生成的动画通过[动画校验](../frame-animation/animation-production.md#6-动画校验先整体动作与画布再看细节)后，为了在游戏里用得顺手，常常还需要二次处理：调整节奏、剔除问题帧、为组合动作准备衔接点。本目录收录这类处理方法。生成前的姿态、画布与提示词仍按[动画制作](../frame-animation/animation-production.md)执行。

## 何时进入后处理

- 动作本身已经正确，但在游戏里显得慢、拖沓或衔接不上：读[加速与裁帧](speed-and-trim.md)。
- 动作要和代码投射物、另一个角色或其他动作组合使用：读[组合动作](combo-assembly.md)。投掷类动作在**生成前**就要按组合方式准备首尾帧，不要等生成完再补救。

动作错误、主体被截断、角色走形等问题不属于后处理，应回到动画制作重新生成。

## 通用原则

1. **保留原片，处理结果另存。** 记录保留了哪些帧、做了哪些加速或倒放，便于复现和回退。
2. **区分两种交付。** 保真原片保持生成时的帧与时序；游戏版可以按手感裁帧、提速和重组。两者都保留，游戏版不覆盖原片。
3. **处理后重新回放。** 按游戏实际播放速度检查节奏、衔接点和锚点；整段使用同一画布与锚点，跨动作对齐仍按[跨动作锚点验收](../frame-animation/animation-alignment.md)执行。
4. **音效同步处理。** 裁帧、变速或倒放后，对应的音效按同样的时间范围处理。
